# Global LayOff From 2020 to 2026

### Project Overview
The Global Layoffs Analysis project focuses on analyzing employee layoffs across companies worldwide from 2020 to 2026.

The project uses SQL for data analysis and Power BI for interactive dashboard development to identify layoff trends, affected industries, companies, countries, and the relationship between company funding and employee layoffs.

The objective is to transform raw layoff data into meaningful business insights that help understand global employment trends.

### Business Problem
Companies across different industries and countries have conducted employee layoffs over the years.

However, understanding the overall layoff situation requires answering several business questions:
- Which companies have laid off the highest number of employees?
- Which industries are most affected by layoffs?
- Which countries have experienced the highest layoffs?
- How have layoffs changed from 2020 to 2026?
- Are companies with higher funding also conducting layoffs?
- Which company stages are experiencing the most layoffs?

This project analyzes these questions using SQL and Power BI.

### Project Objectives

1. Analyze global employee layoffs from 2020 to 2026.
2. Identify companies with the highest number of layoffs.
3. Analyze layoffs across different industries.
4. Compare layoffs across countries.
5. Identify yearly and monthly layoff trends.
6. Analyze layoffs based on company funding and company stage.
7. Build an interactive Power BI dashboard to present business insights.

### Dataset Information
Dataset Name: Layoffs Dataset
Time Period: 2020-2026
Dataset Source: (https://www.kaggle.com/datasets/swaptr/layoffs-2022)

Dataset Columns

| Column Name | Description |
| company | Name of the company conducting layoffs |
| location | Specific company location |
| total_laid_off | Total number of employees laid off |
| date | Date of the layoff announcement |
| percentage_laid_off | Percentage of employees laid off |
| industry | Industry in which the company operates |
| source | Source of layoff information |
| stage | Company funding or business stage |
| funds_raised | Total funding raised by the company during layoff |
| country | Country where the company is located |
